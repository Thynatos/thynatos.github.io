# Fonts

`pagella-*.woff2` are TeX Gyre Pagella by GUST e-foundry, distributed under the
[GUST Font License](https://www.gust.org.pl/projects/e-foundry/licenses).
They were subset to Latin (including Turkish) and saved as WOFF2 by `scripts/build_fonts.py`;
the glyph outlines are unchanged.

Barlow Condensed and IBM Plex Mono are loaded through `next/font/google` (SIL Open Font License).
